# ⚔️ 던전 다이버 (Dungeon Diver)

브라우저에서 바로 즐기는 **턴제 로그라이크** 게임입니다. 설치나 빌드 없이 `index.html`을 열면 바로 플레이할 수 있습니다.

## 목표
무작위로 생성되는 던전을 내려가 **10층**에 잠든 보스 **「심연의 감시자」**를 쓰러뜨리세요. 죽으면 처음부터 다시 — 매 판 던전 구조와 캐릭터 빌드가 달라집니다.

## 실행 방법
- `index.html` 파일을 브라우저로 열면 끝!
- 또는 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속

## 조작법
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (적에게 부딪히면 공격) |
| Q E Z C | 대각선 이동 |
| Space | 한 턴 대기 |
| Enter | 계단 내려가기 |
| 1 ~ 8 | 가방 아이템 사용 |
| M | 소리 켜기/끄기 |

모바일에서는 화면을 탭하거나 아래 방향 패드를 사용하세요.

## 게임 요소
- **턴제 전투**: 내가 한 번 행동하면 모든 적이 한 번 행동합니다.
- **시야 & 안개**: 주변만 보이고, 탐험한 곳은 어둡게 기억됩니다.
- **몬스터**: 🐀 쥐, 🦇 박쥐(2번 이동), 🟢 슬라임(죽으면 분열), 🍄 독버섯(중독), 💀 해골 궁수(원거리), 👹 오크 전사, 👻 망령(벽 통과), 📦 미믹(상자로 위장!)
- **레벨업 특성**: 레벨이 오를 때마다 3개 중 1개 선택 — 흡혈, 가시 갑옷, 반격, 잔상, 재생, 행운 등
- **아이템**: 🧪 회복 물약, 🍷 엘릭서, 🔥 화염 / ❄️ 빙결 / 🌀 순간이동 / 🗺️ 지도 주문서, 🗡️ 무기, 🛡️ 방어구
- **함정**: 숨겨진 가시·독 가스 함정
- **상점**: 3·6·9층에 떠돌이 상인 🧙 등장
- **최고 기록** 저장

## 파일 구성
- `index.html` — 화면 구조
- `style.css` — 스타일
- `game.js` — 게임 로직 전체
